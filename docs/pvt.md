# PVT для расчёта подъёма по стволу

Модуль `services.vlp.pvt` рассчитывает состояние флюида в одной точке ствола по §7.2 ТЗ. На каждом шаге интегрирования VLP передаёт текущие давление и температуру. Расчёт выполняется в том же процессе.

## Вызов из VLP

```python
from services.vlp.pvt import calculate_pvt
from shared.contracts import VlpRequest


def hydraulic_inputs(request: VlpRequest, p_atm: float, t_c: float, q_liq_m3_day: float):
    mix = calculate_pvt(request.pvt, pressure_atm=p_atm, temperature_c=t_c).mixture
    q_work_m3_s = q_liq_m3_day * mix.volume_m3_per_m3_liq / 86_400
    return q_work_m3_s, mix.density_kg_m3, mix.viscosity_cp * 0.001
```

Функция в примере возвращает рабочий объёмный расход в м³/с, плотность в кг/м³ и динамическую вязкость в Па·с. При нулевом дебите расход равен нулю, плотность для гидростатического градиента по-прежнему определена.

| Вход | Значение |
| --- | --- |
| `pressure_atm`, `temperature_c` | Абсолютное давление в точке, физические атм, и местная температура, °C. |
| `fluid.wct` | Обводнённость поверхностной жидкости, %. Объёмная доля воды `w = wct / 100`. |
| `fluid.rp` | Газовый фактор, м³ газа при 20 °C и 1 атм на тонну товарной нефти. Общий газ на м³ нефти `Rp = rp × gamma_oil`, так как её плотность равна `gamma_oil` т/м³. |
| `fluid.gamma_oil`, `gamma_wat`, `gamma_gas` | Относительные плотности. Для нефти и воды опора равна 1000 кг/м³. Для газа опорой служит сухой воздух при 20 °C и 1 атм. |
| `fluid.t_res` | Пластовая температура, °C. VLP использует её при построении температурного профиля. PVT получает готовую местную температуру аргументом `temperature_c`. |

| Поле результата `PvtState` | Единица и смысл |
| --- | --- |
| `mixture.density_kg_m3`, `mixture.viscosity_cp` | Плотность и динамическая вязкость смеси при местных условиях, кг/м³ и сП. |
| `mixture.volume_m3_per_m3_liq` | Суммарный объём фаз при местных условиях на 1 м³ поверхностной жидкости. |
| `oil`, `gas`, `water` | У каждой фазы те же три поля. Объём фазы отнесён к общему поверхностному объёму жидкости. Доля фазы в стволе равна её объёму, делённому на объём смеси. |
| `oil.pb_atm`, `oil.rs_m3_m3` | Давление насыщения при местной температуре, атм. Количество растворённого газа, ст. м³ на м³ товарной нефти. |
| `oil.bo`, `gas.bg` | Объёмные коэффициенты. Для нефти знаменатель — м³ товарной нефти, для газа — стандартный м³ газа. |
| `gas.free_std_m3_per_m3_liq` | Объём свободного газа в **стандартных** м³ на м³ поверхностной жидкости. Умножение на `bg` даёт `gas.volume_m3_per_m3_liq`. |

При 100% воды `mixture` равна `water`, а `oil` и `gas` равны `None`. В нефтесодержащем потоке при `P ≥ Pb` объект `gas` содержит справочные свойства газа и нулевой объём свободной фазы. Для гидравлики во всех случаях достаточно `mixture`.

## Единицы корреляций

Давление API задано в физических атмосферах, температура в °C. В формулах приложения к документу «База знаний Разработка модели скважины» используются `P = 101325 P_atm` (Па), `T = t_C + 273.15` (К), `F = 1.8 t_C + 32` (°F), `API = 141.5/γo − 131.5`. Для степенных формул вязкости и коэффициента сжимаемости используется `R = Rs/0.17810760667903522` (scf/STB), как в приложении 13. Входной параметр Pb модели притока и локальный Pb в расчёте PVT имеют разное назначение.

## Формулы

1. **Растворённый газ и давление насыщения.** Приложения 1 и 4 задают `y = 1.2254503 + 0.001638 T − 1.76875/γo`, `C = 1.9243101395421235×10⁻⁶ / 10ʸ`, `Rs = min(Rp, γg (C P)^(1/0.83))`. Обращение даёт `Pb = (Rp/γg)^0.83 / C` в Па. При P ≥ Pb свободный газ равен нулю.

2. **Объёмный коэффициент нефти.** По приложениям 1 и 4 насыщенное значение равно `Bo = 0.972 + 0.000147 (R √(γg/γo) + 2.25 T − 574.5875)^1.175`. Выше Pb используется `Bo = Bob exp[−k (P − P₀)/P₀]`, где `k = max(0, (−1433 + 5 Rb + 17.2 F − 1180 γg + 12.61 API)/100000)`, Rb в scf/STB и P₀ = max(Pb, 1 атм). Давления в отношении берутся в одной системе единиц. В приложении деление на 10⁻⁵ в записи коэффициента A даёт переполнение либо обнуление Bo при обычных перепадах давления. Принят масштаб Васкес–Беггс 10⁻⁵ как множитель и опорное давление из приложения. [Vasquez и Beggs](https://doi.org/10.2118/6719-PA)

3. **Вязкость нефти, сП.** По приложениям 3 и 6 при F ≥ 70 вычисляется `μd = 10^x − 1`, где `x = 10^(3.0324 − 0.02023 API) / F^1.163`. При 0 < F < 70 используется `μ70 (70/F)^c`, где `c = ln(μ70/μ80)/ln(80/70)`. μ70 и μ80 берутся из тёплой ветви. Для нефти с растворённым газом `μsat = 10.715 (R+100)^(−0.515) μd^[5.44 (R+150)^(−0.338)]`. Выше опорного давления применяется поправка из §7.2 ТЗ `μ = μob (P/P₀)^m`, где `m = 2.6 P^1.187 × 10^(−5 − 0.000039 P)` и P в psia. [Beggs и Robinson](https://doi.org/10.2118/5434-PA)

4. **Газ.** При `z=1` объёмный коэффициент `Bg = (T_K / 293.15) / P_atm`. Стандартная плотность газа `ρg,ст = γg × Pст × Mвозд / (R × 293.15)`, где `Pст = 101325 Па`, `Mвозд = 0.02896546 кг/моль`, `R = 8.314462618 Дж/(моль·К)`. Рабочая плотность `ρg = ρg,ст / Bg`.

5. **Вязкость газа по Carr–Kobayashi–Burrows (1954).** Состав примесей в запросе отсутствует, принят углеводородный газ. При 1 атм `μ1 = (1.709×10⁻⁵ − 2.062×10⁻⁶ γg) T_F + 0.008188 − 0.00615 log10 γg`, результат в сП. Поправка давления следует полиномиальному представлению диаграммы CKB по Dempsey (1965). Его 16 коэффициентов приведены в `correlations.py`. Полином выражает `ln(Tr × μg/μ1)`. Псевдокритические параметры по Sutton равны `Ppc = 756.8 − 131.07 γg − 3.6 γg²` в psia и `Tpc = 169.2 + 349.5 γg − 74 γg²` в °R. Для `Tr` используется абсолютная температура в °R. [Carr, Kobayashi и Burrows, SPE-297-G](https://doi.org/10.2118/297-G) · [Horne, уравнения 11.29–11.30 и коэффициенты Dempsey](https://home.czu.cz/storage/575/52485_Ronald-N-Modern-Well-Test-Analysis.pdf) · [Псевдокритические параметры Sutton](https://www.sciencedirect.com/topics/engineering/pseudocritical-property)

6. **Масса и смешение по §7.2 ТЗ.** Плотность нефти с растворённым газом равна `(1000 γo + Rs × ρg,ст) / Bo`, здесь `Rs` в ст. м³/м³. Для воды `ρw = 1000 γw`, `μw = 1 сП`. На 1 м³ поверхностной жидкости рабочие объёмы равны `Vo = (1−w) Bo`, `Vw = w`, `Vg = (1−w)(Rp−Rs) Bg`. При отсутствии скольжения плотность и вязкость усредняются по этим объёмам в точке. Растворённый газ уже входит в массу нефтяной фазы.

### Границы применения

При Rp = 0 формула даёт Pb = 0. При малом положительном Rp давление насыщения также положительно и может оказаться меньше 1 атм. Нижний предел опорного давления и ограничение k ≥ 0 сохраняют сжимаемость конечной и неотрицательной при экстраполяции. Для вязкости нефти база знаний указывает верхние границы 295 °F и 58 °API. За этими границами значения являются экстраполяцией.

Рабочая область аппроксимации Dempsey — `1 ≤ Pr ≤ 20`, `1.2 ≤ Tr ≤ 3`. Между 1 атм и `Pr=1` используется линейная интерполяция вязкости между двумя опорами. При давлениях ниже 1 атм сохраняется вязкость разреженного газа `μ1`. Результаты вне исходных диапазонов эмпирических корреляций являются экстраполяцией. Для нефти степенная формула вязкости требует `T_F > 0`. Функция отклоняет недопустимое давление, температуру и численно непредставимые результаты через `ValueError`. [Диапазон аппроксимации, Montanuniversität Leoben](https://pureadmin.unileoben.ac.at/WS/portalfiles/portal/1875932/AC13278094n01vt.pdf)

## Числовая проверка

Из корня проекта выполните `python -m scripts.pvt_example`. Пример берёт состав из §5.3 и температуру 90 °C. При `rp=100 м³/т` и `gamma_oil=0.8` запас газа равен 80 ст. м³/м³ товарной нефти. При обводнённости 50% это 40 ст. м³ газа на м³ поверхностной жидкости.

| Абсолютное давление, атм | Растворено, ст. м³/м³ нефти | Свободно, ст. м³/м³ жидкости | Bo | Плотность смеси, кг/м³ | Вязкость смеси, сП |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 50 | 32.157 | 23.921 | 1.1454 | 560.665 | 0.4951 |
| Pb ≈ 106.535448 | 80.000 | 0 | 1.2756 | 820.625 | 0.6614 |
| 150 | 80.000 | 0 | 1.2555 | 827.943 | 0.6792 |

Строка на границе рассчитана при полном машинном значении `oil.pb_atm`. Для первой строки баланс на м³ жидкости даёт `0.5 × 32.157 + 23.921 ≈ 40`. Для 100% воды при `gamma_wat=1` результат равен 1000 кг/м³ и 1 сП.

Ahmed, Reservoir Engineering Handbook, глава 2](https://tic.uis.edu.co/ava/pluginfile.php/97032/mod_folder/content/0/CAP2%20Tarek%20Ahmed%20Reservoir%20Engineering%20Handbook.pdf)
